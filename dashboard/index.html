How to read this page. Implied value is the entry's own claim, never make.fun's: launch value (what the size curve and category effects say a token would be worth, fitted on traded protocols) times token odds (the chance a protocol like this one records a token). A protocol is said to record no token when its DefiLlama record carries none; that is not proof it has none. Farm nets assume a $10,000 deposit held 90 days and a 7% drop share; the T-bill benchmark on the same deposit is $111 over 90 days. Nothing here is a hardcoded list of names: rerun the program and every number recomputes from the snapshot.
